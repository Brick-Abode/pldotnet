# Tests

This document provides an overview of the tests available in
the pldotnet project, which includes both C# and F#. The tests are
organized into different categories, each serving a specific purpose.

## 1. _pldotnet_ tests

Our PL/.NET tests are designed to be run in a docker container.
To run our tests, you can use the `make` command. It requires 2 steps:

1. **Start the PostgreSQL + PL/.NET dev container**: This step is necessary to
   ensure that the PostgreSQL instance is running, PL/.NET is installed, and ready for testing.
   You can do this by running the following command:

   ```bash
   make dev
   ```

2. **Run the tests**: After starting the dev container, you can run the tests
   using the following command in a separate terminal:

   ```bash
   make test-docker
   ```

   If you would like to run only C# or F# tests, you can use one of the following commands:

   ```bash
   make XUNIT_FILTER="CSharp" test-docker
   make XUNIT_FILTER="FSharp" test-docker
   ```

The output is saved inside the `automated_test_results` folder with
the `<testfile>.out` name. A summary of all of them is placed with
the `automated_test_results.out` name.

That's it.  
If you are having trouble running the tests, you may want
to check the documentation or seek help from the relevant support
channels.

Our system has tests for all the implemented types, and you can use
these tests to help you become productive quickly.
